# Codex GeoGebra Pic for Codex

Requires Chrome, Chromium, or Edge and access to the GeoGebra web renderer. The DSH workspace panel is replaced by PNG/SVG/GGB exports.

See the collection README for installation. No DSH process is required. Node.js 22 or newer is required.

Optional configuration: copy config.example.json outside the plugin cache and set CODEX_GEOGEBRA_PIC_CONFIG to its absolute path before starting Codex. The JSON uses the original plugin configuration fields. Installed files may be refreshed; keep personal settings outside the package.

Original source: geogebra-pic, version 0.3.1. Adapter version: 1.0.0.
